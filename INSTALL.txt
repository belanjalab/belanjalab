BELANJALAB UI/UX STAGE 3 — DECISION PLATFORM DIFFERENTIATION

CARA PASANG
1. Ekstrak ZIP ini di root project BelanjaLab.
2. Izinkan seluruh file lama ditimpa.
3. Jalankan:

   npm run typecheck
   npm run build

4. Setelah kedua perintah berhasil, commit dan deploy seperti biasa.

FILE YANG DIGANTI / DITAMBAHKAN

PERUBAHAN UTAMA
- Product card menjadi kartu keputusan: kekuatan utama, skor, verdict, harga, jumlah sumber harga, dan waktu cek.
- Quick comparison membandingkan dua featured product dari kategori yang sama.
- CTA compare membawa slug produk ke /compare?products=slug-1,slug-2 dan langsung memilih produk tersebut.
- Metodologi BelanjaLab Score serta transparansi harga dijelaskan di homepage.
- Harga hanya memakai penawaran yang tersedia dan tidak berstatus out_of_stock.
- Freshness memakai last_checked_at, lalu updated_at sebagai fallback.

DATABASE
Tidak ada migration SQL baru. Stage ini memakai kolom dan relasi yang sudah tersedia pada project:
short_description, brands, product_scores, product_prices, marketplaces,
last_checked_at, dan updated_at.

CATATAN QA
- Responsive visual QA: 390 px, 820 px, dan 1440 px.
- Tidak ditemukan horizontal overflow.
- Tidak ditemukan teks fixed-size di bawah 12 px pada komponen homepage baru.
- Tombol/input/summary utama tidak ditemukan di bawah 44 px.
- Pemeriksaan TypeScript terisolasi berhasil.
- Build Next.js penuh tetap harus dijalankan di mesin project karena dependency registry tidak tersedia di lingkungan pembuatan paket.
