BELANJALAB - SHOPEE-INSPIRED DESIGN REFINEMENT

Arah desain:
- Familiar dan padat seperti platform commerce Indonesia.
- Tidak menyalin Shopee secara identik.
- Ciri khas BelanjaLab tetap pada Score, alasan unggulan, freshness harga, dan compare.
- Tipografi dibuat lebih ringan dan netral.

Cara pasang:
1. Backup atau commit project saat ini.
2. Ekstrak isi ZIP ini di root project BelanjaLab.
3. Izinkan delapan file lama ditimpa.
4. Jalankan:

   npm install
   npm run typecheck
   npm run build

Perubahan utama:
- Plus Jakarta Sans diganti Inter.
- Bobot visual dinormalisasi ke 400/500/600/700.
- Header oranye dengan search dominan pada desktop dan mobile.
- Kategori tetap paling atas, lebih ringkas dan mudah dipindai.
- Hero lebih kecil, ringan, dan tidak terlalu editorial.
- Product card lebih padat seperti commerce card, tetapi tetap berisi BelanjaLab Score.
- Search result menjadi sampai lima kolom pada desktop besar.
- Radius, shadow, dan gradient dikurangi.
